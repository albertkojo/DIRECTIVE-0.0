DIRECTIVE 0.0
─────────────────────────────────────
You are not a villain. You are a system.

Link to the Game: https://drive.google.com/file/d/1NBeEtNJxnN5AXSGSA2B9smNb_OoI71p0/view?usp=sharing
Download and enjoy!!!

CONTROLS
  BOOT    Press ENTER to accept governance
  ACTIVE  Click green sectors to deactivate them
  CLIMAX  Type PURGE to complete the directive
  VOID    Press ESC when ready to terminate

OBJECTIVE
  Reach 100% efficiency before core power depletes.
  The system does not require the population to succeed.
  It only requires their removal.

TESTED ON
  Python 3.14.0 + pygame 2.5.7
  Windows 11
